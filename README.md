# sanitize

Утилита для Linux (CLI + GUI на Qt), которая рекурсивно находит в веб-проекте
(в первую очередь — CMS 1С-Битрикс) файлы с персональными данными и секретами
и обнуляет их (по умолчанию) или удаляет (`--delete`).

> Документация в наполнении — см. AGENTS.md. Раздел «Быстрый старт» появится в фазе 3.

## Разработка

```bash
uv sync --all-extras      # установка зависимостей
uv run pytest -q          # тесты
uv run ruff check .       # линтер
uv run mypy sanitize/core # типы ядра
```
