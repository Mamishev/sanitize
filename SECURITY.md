# Безопасность

Не публикуйте секреты и персональные данные в issues.
Для уязвимостей используйте private vulnerability reporting на GitHub,
если он включён, либо свяжитесь с автором: info@wmast.ru.

sanitize не гарантирует полную анонимизацию проекта: изображения, БД,
история Git и другие источники вне охвата могут содержать данные.
Проверяйте результат перед передачей проекта.
