## [1.0.1] — 2026-11-06

### Изменено (GUI)
- Кнопка «Обзор…» открывает диалог выбора каталога с домашней папкой
  пользователя.
- В области «Параметры поиска» одновременно открыт только один попап «?»:
  клик по другой кнопке «?» закрывает предыдущую подсказку.
- Область результатов: категории с > 10 файлами свёрнуты по умолчанию
  (≤ 10 — развёрнуты); группы внутри развёрнутой категории раскрыты.
- Группировка больших категорий: при > 20 файлах файлы собираются в группы
  с tri-state чекбоксами; селектор «Нет / По каталогам / По расширениям»
  рядом с фильтром, режим запоминается в QSettings; состояние чекбоксов
  сохраняется при смене режима.
- Колонка «Файл» в 4 раза шире остальных (пропорция 4:1:1, пересчёт при
  ресайзе окна).
- Кликабельные подсказки: у каждого чекбокса области «Параметры поиска»
  кнопка «?» с подробным пояснением в попапе (14 подсказок); краткий
  hover-тултип сохранён.

### Добавлено
- `docs/user-guide.md` — руководство пользователя (установка, CLI, GUI, TUI,
  профили, отчёты, карантин, FAQ).

### Исправлено
- Изоляция QSettings в GUI-тестах: уникальный ini-файл на тест (нативный
  QSettings кеширует путь конфига на процесс — состояние «чекбоксов»
  протекало между тестами).

## [1.0.0] — 2026-11-06

Первый стабильный релиз: утилита поиска и обезвреживания файлов с ПДн
и секретами в веб-проектах (в первую очередь CMS 1С-Битрикс). Linux, CLI + GUI.

### Добавлено

#### Ядро
- Сканер: обход `os.scandir`, классификация (точные пути → имена → шаблоны →
  каталоги → расширения, двойные раньше одинарных), исключённые каталоги
  Битрикс, рискованные каталоги, `only_under` (.txt/.md только под `upload/`),
  симлинки, `one_filesystem`, фильтры размера/возраста, отмена
  (`threading.Event`), троттлинг прогресса.
- Профили `bitrix` и `generic` (TOML с валидацией): 10 категорий — документы,
  таблицы/экспорт, презентации, архивы, подписи/ключи, бэкапы/дампы, почта,
  аудио/видео (выкл.), логи и кэш, конфиги с секретами (только отчёт).
- Действия: `zero` (по умолчанию, с сохранением uid/gid/mode/mtime,
  идемпотентно), `delete` (каталоги не трогает), `stub` (минимально валидные
  PDF/zip/текст), `quarantine` (tar.gz + `manifest.json`, каталог вне корня).
- `sanitize restore ARCHIVE [--dry-run]` — восстановление из карантина
  (без перезаписи существующих файлов, атрибуты восстанавливаются).
- Отчёты JSON/Markdown: метаданные запуска, сводка по категориям, файлы,
  действия с sha256, пропуски. Автоотчёт `sanitize-report.json` в GUI.
- `safety`: чёрный список корней (`/`, `/home`, `/usr`, `/etc`, `/var`, …),
  маркеры проекта, quarantine вне root, предупреждение о `.git`.
- `magic` (`--magic`): тип по сигнатуре для файлов без расширения,
  graceful fallback без libmagic.
- `deep-scan` (`--deep-scan`): ПДн по содержимому — e-mail, телефон РФ,
  паспорт, СНИЛС и ИНН с контрольными суммами, карта (Луна); текстовые
  форматы и docx/xlsx как zip; лимит чтения 20 МБ/файл.
- `.sanitizeignore` в корне проекта (подмножество gitignore).
- Многопоточный обход (`--threads`, ThreadPoolExecutor по подкаталогам
  первого уровня); ~46k файлов/с на 205k-дереве.

#### CLI
- Полный набор опций (раздел 7 AGENTS.md), exit-коды 0/1/2/3/130,
  `--dry-run`, подтверждения (для `--delete` — ввод `DELETE`),
  `--json`, `--report FILE.json|FILE.md`, `--sql FILE` (скрипт `b_file`
  `FILE_SIZE = 0`), `sanitize restore`, `--gui`, `--tui`, `--version`.

#### GUI (PySide6)
- Единственное окно: параметры → прогресс (подсчёт каталогов → детерминированный)
  → дерево результатов (tri-state чекбоксы, фильтр, сортировка, контекстное
  меню) → действия (обнулить/удалить/карантин). Сканер и действия в QThread,
  отмена < 1 с. Секреты — только просмотр. Подсказка `sudo` при ошибках
  доступа. Настройки в QSettings. Горячие клавиши Ctrl+F / Enter / Esc.

#### TUI (Textual, extras `tui`)
- Минимум для headless-стендов по SSH: путь, чекбоксы категорий, таблица
  найденного, обнуление/удаление с подтверждением (ввод `DELETE`).

### Безопасность по умолчанию
- `--dry-run` не меняет ни одного байта; без TTY и без `--yes` — отказ (код 3).
- Конфиги с секретами никогда не изменяются (защита в CLI, GUI и ядре).
- Симлинки не обходятся и не изменяются; скрытые файлы — только с
  `--include-hidden`.
