sanitize 1.0.2 — Linux x86_64

- Иконка шрёдера, привязанные к кнопкам подсказки, меню «Справка» и F1.
- Собственный код и документация под 0BSD.
- AppImage: GUI без установленного Python; аргументы командной строки доступны.
- Wheel/sdist для установки CLI через uv/pipx.

В комплекте: руководство, SHA256SUMS, уведомления зависимостей и их исходники.
Проверки переносимости: Ubuntu 24.04/26.04, Debian 13, X11 и Wayland
в изолированных контейнерах. Это smoke-проверки запуска, не ручная проверка
всех окружений рабочего стола. Qt-библиотеки можно заменить после извлечения
AppImage (см. docs/third-party.md).

Ограничения: очистка файлов не является полной анонимизацией проекта.
БД, изображения и история Git могут сохранять данные. Финальная проверка
сайта и админки Битрикс на развёрнутом стенде после очистки ещё не завершена.
