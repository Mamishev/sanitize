# Проверка кандидата 1.0.2 — 2026-11-06

- Ruff check/format, strict mypy ядра, полный pytest проходят.
- Wheel/sdist собираются. Wheel установлен в чистое окружение вне репозитория:
  версия, профили, GUI, меню справки и иконки доступны.
- AppImage собран на Ubuntu 24.04 x86_64, Python 3.12, PyInstaller 6.16.0,
  hooks 2026.9; зависимости Python фиксирует uv.lock.
- appimagetool и runtime проверены по SHA256 GitHub release assets.

  Weston/Wayland. В runtime-образах не установлен Python.
- Проверены --version, magic, dry-run без изменения файла, zero,
  skipped_empty, исключённый каталог, симлинк и внешний файл.
  Все сканирования/действия выполнялись только на mktemp-фикстурах.

  системных шрифтов. Визуальное качество всех элементов вручную не подтверждено.

  находок нет. Это автоматическая проверка, не гарантия отсутствия всех секретов.

- Из скрипта SQL удалены локальные значения путей по умолчанию. Старые пути

- Подготовлены тексты лицензий, METADATA и source-kit (Qt/PySide6, ICU,
